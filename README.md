# 우리 몸 탐구실
6학년 과학 「우리 몸의 구조와 기능」 모둠 발표 후 학습자료입니다.

- 학생 화면: https://ybs5546.github.io/body-learning-lab/
- 교사 화면 및 저장 API: https://body-lab-sixth-grade.foggybread14.chatgpt.site/teacher
- 학습 주제: 소화, 순환, 호흡, 배설, 운동 시 기관의 협력, 질병과 예방
- 주제별 설명·도식, 선택형 2문제, 서술형 1문제, 정답·해설, 관계쓰기
- 학급 코드·번호·이름으로 제출, 교사는 ChatGPT 로그인 후 자신의 학급만 조회

## 실행과 배포
Node.js 24에서 `npm ci` 후 `npm run dev`.
`node node_modules/vite/bin/vite.js build --config vite.pages.config.ts`는 학생용 정적 산출물을 `docs/`에 생성합니다.
GitHub Pages가 main 브랜치의 docs/ 폴더를 배포합니다. 변경 후 정적 빌드를 실행하고 docs/ 산출물도 함께 커밋합니다.
서버는 Sites의 Vinext/Cloudflare Workers와 D1을 사용합니다. 정적 Pages 자체에는 개인정보나 데이터베이스를 넣지 않습니다.

Sites 환경변수 `PAGES_ORIGIN=https://ybs5546.github.io`가 학생 요청 출처를 허용합니다.
새 호스팅 계정으로 복제할 때는 Sites 프로젝트를 새로 등록하고 student-web/index.html의 API 주소 및 교사 공유 링크를 수정해야 합니다.
학생용 정적 화면은 로컬 MCP를 호출하지 않습니다. 교육과정 MCP는 저작 과정에서만 사용했습니다.

## 교사 사용법
1. 교사 화면에 ChatGPT로 로그인해 학급을 만듭니다.
2. 학생에게 학급 코드와 학생용 링크를 안내합니다.
3. 학생은 발표 후 해당 주제에 답하고 해설을 확인한 뒤 생각을 써 제출합니다.
4. 교사 화면에서 학생별·주제별 답안을 읽고 CSV를 내려받습니다.
5. 기기 변경이 필요하면 학생 행의 복구 코드를 생성해 해당 학생에게만 전달합니다. 기존 토큰은 해제되며 제출 답안은 유지됩니다.
6. 수업 종료 후 제출을 닫을 수 있습니다. 필요가 끝난 학급은 삭제할 수 있습니다.

질병 조사 증거는 학생들의 발표 준비자료와 함께 판단하세요. 선택형만 자동 채점하며 서술형은 교사가 읽습니다.

## 검증
로컬 서버에서 `node tests/api-smoke.mjs`로 학급 생성, 익명 접근 차단, 중복 번호, 제출·수정, 마감, 토큰 복구, 출처 검사를 시험합니다.
테스트는 로컬 127.0.0.1:5173만 대상으로 하고 자체 생성한 시험용 학급을 제거합니다.
`node node_modules/typescript/bin/tsc --noEmit`로 타입을 확인합니다.

## 공개 범위
코드, 교육용 콘텐츠, 도식만 공개합니다. 학생 답안, 이름, 토큰, 로컬 DB, .env, 실행 로그는 저장소에 포함하지 않습니다.
학생 답안은 선생님의 학급에만 저장되며 학생 간 답안 조회 기능은 없습니다.
